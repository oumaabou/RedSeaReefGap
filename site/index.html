RedSeaReefGap

Where does the public biodiversity record for Red Sea reef fish actually have data — and where is it silent? A GBIF-based sampling-effort gap analysis, built in R.

GitHub repository · Full methodology & limitations

The question

This project looks at six common Red Sea reef-fish families — surgeonfishes, tunas & mackerels, parrotfishes, jacks, groupers, and snappers — through the lens of the Global Biodiversity Information Facility (GBIF). Rather than mapping where these fish live, it maps where they have been recorded, which for citizen-science-heavy data turns out to be a very different, and much more revealing, question.

Headline numbers

70–85% of every family's GBIF records come from a single country — Egypt — concentrated on two Sinai dive sites
70–82% of dated records are from 2015 onward, tracking iNaturalist's growth rather than fish abundance
<5% typical combined share of records from Sudan, Eritrea, Yemen & Djibouti per family

In practice: a trend read directly off raw GBIF record counts for these families is, to a large extent, a trend in dive tourism and app usage — not necessarily a trend in the fish themselves.

Method, in brief

All figures come from live queries against the GBIF Occurrence API, restricted to a Red Sea bounding box (12–30°N, 32–44°E). Country and year breakdowns use GBIF's own facet counts, which cover every matching record — not a sample. The full R pipeline (clean → spatial gap → temporal gap → map) runs automatically on GitHub Actions on every push, so these charts are regenerated from a real, reproducible run rather than asserted. See the Scope and limitations section of the README for the caveats (GBIF-only, bounding-box edge cases, citizen-science bias).
